

### 🤖 Prompt for the AI Agent:

**System Role:** You are an expert React and Web3/Cyberpunk UI Developer. Your task is to build a high-tech, futuristic web interface for a real-time CCTV spatial occlusion tracking system (VL-JEPA). 

**Tech Stack:** React (Vite setup), Tailwind CSS, and `lucide-react` for icons.

**1. General Aesthetic & Theming (Cyberpunk / High-Tech)**
- **Background:** Use a deep, dark radial gradient (e.g., `radial-gradient(ellipse at 40% 30%, #0f172a 0%, #020617 60%, #000000 100%)`). 
- **Typography:** Import `Exo 2` for primary UI text and `Share Tech Mono` for all data readouts, timestamps, and confidence percentages.
- **Visual Effects:** 
  - Add a subtle, continuous downward CSS `scanline` animation over the entire screen.
  - Implement heavy "Glassmorphism" for all panels (e.g., `bg-white/5 backdrop-blur-md border border-white/10`).
  - Add sharp neon drop-shadows under active elements. Use a distinct color palette tailored for 15 specific actions (e.g., Blue neon for "Closing", Purple for "Covering", Red for "Hitting", etc.).

**2. State Management & Data Logic**
The application needs to handle three distinct context modes, selected via buttons:
1. **Live Camera Mode:** Uses `navigator.mediaDevices.getUserMedia` to hook up the user's webcam. Extracts frames via a hidden `<canvas>` every 800ms, converts them to base64, and pushes them via a WebSocket connection to `wss://<BACKEND_URL>/ws/predict`.
2. **Video Upload Mode:** A drag-and-drop zone. Pushes the `.mp4` file via `FormData` to an HTTP POST endpoint at `http://<BACKEND_URL>/predict/video` and parses the returned JSON `events` array.
3. **Simulation Mode:** A local static demonstration loop that runs through mock actions.

**3. Core Layout Structure**
-**Header:** Minimalistic top bar with a flickering neon "SYSTEM STATUS: ACTIVE" indicator, timestamp, and a connection status badge (Green = WS Connected, Red = Disconnected).
- **Main Grid (2 Columns):**
  - **Left Column (Visual Feed):** The primary view holding the `<video>` element. Above the video, place an absolute positioned HUD overlay showing the current active prediction (Action Name and % Confidence). Include a **"Simulate Blindspot"** toggle switch that renders a dark, translucent rectangle over the center/right of the video to mock a camera occlusion.
  - **Right Column (Control Console):** 
    - Input parameters box for the `targetText` (Target Action Prompt).
    - Source Selection Tabs (Webcam, Upload, Simulation).
    - **Current Readout Panel:** A highly stylized terminal box displaying the current active Action, the exact Timestamp, and a glowing `ConfidenceBar` (a customized progress bar where the width represents the prediction probability).
- **Bottom Row (Temporal Timeline):**
  - A horizontal axis representing the duration of the current session or uploaded video.
  - As predictions return from the backend, inject `<TimelineBlock>` elements absolutely positioned across the X-axis. 
  - Each block should have a specific neon background color, border, and "pulsing" CSS animation when active, displaying the action name and start/end bounds.

**4. WebSocket Payload Specs**
When sending to the backend, the payload sent via WebSocket should look like this:
```json
{
  "image": "<base64_string_without_prefix>",
  "timestamp": "LIVE",
  "prompt": "describe the action",
  "blindspot": true,
  "source": "camera"
}
```
The Backend will return a JSON object like this:
```json
{
  "action": "Closing something",
  "confidence": 0.89,
  "timestamp": "LIVE",
  "occluded_action": "Closing something"
}
```

**Task:** Generate the complete `App.jsx` and essential tailwind CSS class structures to bring this cyberpunk CCTV interface to life. Ensure all hooks (`useRef`, `useEffect` for the WS and `<video>` tags) are perfectly optimized to prevent memory leaks from the 800ms frame capture interval.
